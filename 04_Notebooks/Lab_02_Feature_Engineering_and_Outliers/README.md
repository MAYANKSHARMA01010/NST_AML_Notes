# Lab 02: Feature Engineering, Outlier Treatment & Scaling

## Overview
This lab covers essential techniques for preparing tabular data for machine learning models:
- **Feature Engineering**: Creating interaction features, domain-specific indicators, and encoding strategies.
- **Outlier Detection & Treatment**: IQR (Interquartile Range) filtering, Z-score thresholds, and winsorization.
- **Feature Scaling**: StandardScaler (Z-score standardization), MinMaxScaler, and RobustScaler.
- **Machine Learning Readiness**: Checking correlation matrices, multicollinearity, and preparing feature matrices (`X`) and target vectors (`y`).
