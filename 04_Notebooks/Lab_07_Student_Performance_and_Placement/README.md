# Lab 07: Student Performance & Placement Analysis

## Overview
A comprehensive story-driven lab assignment that integrates the end-to-end machine learning pipeline:
- **Data Ingestion**: Reading and inspecting `student_raw_dataset.csv`.
- **Cleaning & Preprocessing**: Handling corrupted entries, null values, and categorical encodings.
- **Exploratory Data Analysis**: Visualizing score distributions, attendance impact, and placement factors.
- **Outlier Treatment & Normalization**: Applying robust statistical techniques.
- **Modeling & Evaluation**: Building predictive models to understand student outcomes and placement probabilities.

## Contents
- [`Lab_07_Student_Performance_and_Placement.ipynb`](Lab_07_Student_Performance_and_Placement.ipynb): Main assignment story notebook with step-by-step TODOs and experiments.
- `student_raw_dataset.csv`: Dataset containing student academic records, attendance, study habits, and placement status.

## Environment
Runs under the unified AML shared virtual environment (`aml-env` / `Python 3 (AML Course)`).
