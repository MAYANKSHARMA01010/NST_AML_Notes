# Lab 01: Exploratory Data Analysis (EDA) & Preprocessing

## Overview
This lab focuses on the foundational steps of machine learning workflows:
- Loading and understanding raw tabular datasets.
- Inspecting data quality, identifying missing values, and detecting anomalous data types.
- Univariate, bivariate, and multivariate exploratory data analysis using `pandas`, `matplotlib`, and `seaborn`.
- Handling missing data, type casting, and standardizing categorical columns.
