## Section 1: The Storyline — From Data to a Prediction Question

### 1. The Hook
> **The Story:** Suppose you have a dataset of university students at NST. For each student, you know their final **CGPA** and the monthly **internship stipend** (in thousands of rupees, ₹k) they received.  
> A new junior walks up to you and says: *"My CGPA is 8.2. Based on historical data, what stipend can I expect to receive?"*

How can a computer answer this question objectively? Let's inspect the historical data:

| Student | CGPA ($x$) | Stipend in ₹k ($y$) |
| :---: | :---: | :---: |
| **A** | 8.0 | 50 |
| **B** | 9.0 | 75 |
| **C** | 7.0 | 45 |
| **D** | 7.5 | 40 |
| **E** | 6.0 | 30 |

If you plot these points on a 2D scatter plot:
* **Horizontal axis ($x$):** CGPA (Input Feature / Independent Variable)
* **Vertical axis ($y$):** Stipend (Output Target / Dependent Variable)

```
Stipend (y)
   ^
80 |                  • (B: 9.0, 75)
60 |          • (A: 8.0, 50)
40 |       • (D: 7.5, 40)
   |    • (C: 7.0, 45)
20 | • (E: 6.0, 30)
 0 +----------------------------------> CGPA (x)
   0    2    4    6    8   10
```

You will notice an unmistakable trend: **As CGPA increases, stipend also tends to increase.**  
Because both inputs ($x$) and correct historical outputs ($y$) are known, this is a classic problem of **Supervised Learning** (specifically, **Continuous Regression**).

## Section 2: The Straight-Line Model & Infinite Candidate Lines

To capture this relationship, we propose a straight-line mathematical model:

$$\hat{y} = mx + c$$

*(In statistics literature, this is also commonly written as $\hat{y} = \beta_1 x + \beta_0$ or $\hat{y} = w_1 x + w_0$).*

### Breaking Down Every Symbol:
* **$\hat{y}$ ("y-hat"):** The **predicted** output generated by our model for a given $x$.
* **$x$:** The **input feature** (the student's CGPA).
* **$m$ (Slope / Weight):** Measures how steeply the prediction changes for every 1-unit increase in $x$.  
  *(If $m = 10$, each extra 1.0 CGPA increases predicted stipend by ₹10k).*
* **$c$ (Intercept / Bias):** The predicted value when $x = 0$ (where the line crosses the vertical $y$-axis).

---

### The Infinite Candidate Lines Dilemma

The straight-line equation has **two adjustable numbers (learnable parameters): $m$ and $c$**.  
Different students looking at the exact same scatter plot might guess different lines:

| Student | Chosen Slope ($m$) | Chosen Intercept ($c$) | Resulting Model Equation |
| :---: | :---: | :---: | :---: |
| **Student 1** | $10$ | $-30$ | $\hat{y} = 10x - 30$ |
| **Student 2** | $12$ | $-40$ | $\hat{y} = 12x - 40$ |
| **Student 3** | $8$ | $-10$ | $\hat{y} = 8x - 10$ |

* Changing **$m$** rotates and tilts the line.
* Changing **$c$** slides the line up or down.
* By varying $m$ and $c$, you can draw **infinitely many straight lines** through the 2D plane!

> 💡 **The Core Engineering Problem:**  
> Out of infinitely many possible straight lines, which single line is mathematically the **best**?  
> We cannot rely on human eyesight or gut feeling. We need an objective, unambiguous mathematical criterion that a computer can compute.

## Section 3: What If We Have Two Input Variables?

Before finding the best line, let's understand what happens when real-world complexity increases. Suppose we collect an additional feature: the student's **IQ score**:

| Student | IQ ($x_1$) | CGPA ($x_2$) | Stipend in ₹k ($y$) |
| :---: | :---: | :---: | :---: |
| **A** | 110 | 8.0 | 50 |
| **B** | 120 | 9.0 | 75 |
| **C** | 90 | 7.0 | 45 |
| **D** | 100 | 7.5 | 40 |
| **E** | 95 | 6.0 | 30 |

With two input features, our model becomes:

$$\hat{y} = m_1(x_1) + m_2(x_2) + c = m_1(\text{IQ}) + m_2(\text{CGPA}) + c$$

* $m_1$ controls how stipend changes with IQ.
* $m_2$ controls how stipend changes with CGPA.
* $c$ is the base intercept.

### Geometric Interpretation:
* **1 Input Feature ($x$):** The model is a **1D line** living in 2D space.
* **2 Input Features ($x_1, x_2$):** The model is a **2D flat plane** living in 3D space!
* **$d$ Input Features ($x_1, \dots, x_d$):** The model is a **hyperplane** living in $(d+1)$-dimensional space.

```
       1 Input Feature                   2 Input Features
       
       y (Stipend)                       y (Stipend)
       ^                                 ^
       |      / (Line)                   |       /---------/ (Plane)
       |     /                           |      /         /
       |    /                            |     /---------/
       +-------------> x (CGPA)          +-----------------> x2 (CGPA)
                                          \
                                           \-> x1 (IQ)
```

## Section 4: Formal Notation — Residuals and Errors

Returning to the single-variable case:
* Each data point in our training set is represented as $(x_i, y_i)$ for $i = 1, 2, \dots, n$.
* For any chosen candidate line, the model's prediction for the $i$-th student is:

$$\hat{y}_i = m x_i + c$$

Because real-world data points never fall perfectly on a single straight line, there will almost always be a gap between what the student actually received ($y_i$) and what our line predicted ($\hat{y}_i$).

We define the **error** (or **residual**) at the $i$-th data point as:

$$e_i = y_i - \hat{y}_i = y_i - (m x_i + c)$$

```
Stipend (y)
   ^
   |           • Actual point (xi, yi)
   |           |
   |           |  <--- Vertical Residual: ei = yi - y_hat_i
   |           |
   |       ----+---- Model line: y_hat = m*x + c
   |          / \
   |         /   Predicted point (xi, y_hat_i)
   +---------------------------------------------> CGPA (x)
             xi
```

### ⚠️ Why Do We Measure Vertical Distances (Not Perpendicular)?
Notice that $e_i$ is measured strictly along the **vertical $y$-axis**:
* In regression, the input feature $x_i$ (CGPA) is assumed to be **fixed, known, and given without error**.
* We are only trying to explain and predict the uncertainty in **$y_i$** (Stipend).
* Therefore, the error is purely the vertical difference: $y_i - \hat{y}_i$.  
  *(Measuring perpendicular distances is done in orthogonal regression / PCA, not standard OLS regression).*

---

### 📝 Practice P3: Compute a Residual

Suppose our candidate model is $\hat{y} = 10x - 30$, and student A's data point is $(x = 8.0, y = 50)$.

* **Step 1 — Compute the predicted value:**  
  $$\hat{y} = 10(8.0) - 30 = 80 - 30 = 50$$
* **Step 2 — Compute the residual:**  
  $$e = y - \hat{y} = 50 - 50 = 0$$
* **Interpretation:** The residual is exactly $0$. The prediction line passes right through Student A's point!
  * If $e_i > 0$: The actual point lies **above** the line (the model underestimated).
  * If $e_i < 0$: The actual point lies **below** the line (the model overestimated).

## Section 5: Building the Loss Function — The Three Attempts

If a line has small residuals across all data points, it is a good model. If it has massive residuals, it is a terrible model.  
To let a computer automatically find the best line, we must condense all individual residuals $e_1, e_2, \dots, e_n$ into **a single combined score** called the **Loss Function** (or Cost Function).

Let's examine the three natural ways we could combine these errors:

---

### Attempt 1: Minimize Total Signed Error ($\sum e_i$)

The simplest idea is to just add all errors together:

$$\text{Total Signed Error} = \sum_{i=1}^n e_i = \sum_{i=1}^n (y_i - \hat{y}_i)$$

#### ⚠️ The Fatal Flaw: The Cancellation Trap
Positive and negative errors cancel each other out! Consider a model with 6 data points that makes these errors:

| Point | 1 | 2 | 3 | 4 | 5 | 6 |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **Error ($e_i$)** | $+10$ | $+5$ | $+4$ | $-10$ | $-3$ | $-6$ |

$$\sum_{i=1}^6 e_i = 10 + 5 + 4 + (-10) + (-3) + (-6) = 0$$

The total signed error is **$0$**!  
A computer looking only at this score would believe this model is 100% perfect, even though it missed the first point by a massive $+10$ and the fourth point by $-10$!  
**Verdict: Plain sum of errors is completely broken and cannot be used.**

---

### Attempt 2: Minimize Total Absolute Error ($\sum |e_i|$)

To stop positive and negative errors from canceling, take the absolute value of each error:

$$\text{Total Absolute Error} = \sum_{i=1}^n |e_i| = \sum_{i=1}^n |y_i - m x_i - c|$$

Whether $e_i = +10$ or $e_i = -10$, $|e_i| = 10$. No cancellation is possible!

#### ⚠️ The Fatal Flaw: Calculus Fails at the Corner!
To find the minimum of any function in calculus, we take the derivative and set it to zero ($\frac{d}{de} = 0$).  
Look at the graph of $|e|$:

```
    |e|
     ^
     \       /
      \     /     Slope = +1  (for e > 0)
       \   /
        \ /       Slope = -1  (for e < 0)
   ------+-------> e
         0
       (Sharp V-corner: Derivative undefined!)
```

* For $e > 0$: $\frac{d}{de}|e| = +1$
* For $e < 0$: $\frac{d}{de}|e| = -1$
* **At $e = 0$:** The graph has a sharp, jagged corner. The derivative **does not exist**!

Because $|e|$ is not smoothly differentiable everywhere, you cannot solve for $m$ and $c$ with clean analytical calculus formulas. (You would need linear programming or numerical approximations).

#### 💡 The Outlier Advantage of Absolute Error:
Absolute error penalizes errors **linearly**. If an error is $1$, penalty is $1$. If an error is $10$, penalty is $10$. It does not blow up giant errors out of proportion, making it very **robust to outliers**.

---

### Attempt 3: Minimize Total Squared Error ($\sum e_i^2$) — The OLS Winner! 🏆

Instead of taking absolute values, **square each error**, then sum:

$$E(m, c) = \sum_{i=1}^n e_i^2 = \sum_{i=1}^n (y_i - m x_i - c)^2$$

This is the loss function of **Ordinary Least Squares (OLS)**!

### Why Squared Error Is Perfect for Calculus:
1. **Always Non-Negative ($e_i^2 \ge 0$):** Negative errors become positive when squared ($(-10)^2 = 100$). Zero cancellation!
2. **Smoothly Differentiable Everywhere:** The curve $e^2$ is a smooth, continuous parabola. Its derivative is $\frac{d}{de}(e^2) = 2e$, which exists smoothly at every single point, including $e = 0$.
3. **Severe Penalty on Large Blunders:** A mistake of $1$ gets a penalty of $1^2 = 1$. But a mistake of $10$ gets a penalty of $10^2 = 100$!

#### ⚠️ The Tradeoff: Extreme Sensitivity to Outliers
Because large errors are squared, an error that is $10\times$ larger receives a penalty that is **$100\times$ larger**! A single corrupt outlier point far away from the data will pull the regression line strongly toward itself.

---

### Loss Function Comparison Table

| Property | Signed Error ($\sum e_i$) | Absolute Error ($\sum |e_i|$) | Squared Error ($\sum e_i^2$) |
| :--- | :---: | :---: | :---: |
| **Prevents Cancellation?** | ❌ No | ✅ Yes | ✅ Yes |
| **Smoothly Differentiable?** | ✅ Yes | ❌ No (kink at $0$) | ✅ Yes (smooth parabola) |
| **Allows Closed-Form OLS?** | ❌ No | ❌ No | ✅ **Yes (clean calculus)** |
| **Penalty on Error = 1** | $1$ | $1$ | $1$ |
| **Penalty on Error = 2** | $2$ | $2$ | $4$ ($2\times$ error $\to 4\times$ penalty) |
| **Penalty on Error = 10** | $10$ | $10$ | $100$ ($10\times$ error $\to 100\times$ penalty) |
| **Robust to Outliers?** | ❌ No | ✅ **High (Linear)** | ❌ **Low (Quadratic sensitivity)** |

## Section 6: Closed-Form vs. Iterative Solutions

In machine learning, there are two fundamentally different ways to find optimal model parameters:

```
                      +---------------------------------------+
                      |   How to Find the Minimum Loss?       |
                      +-------------------+-------------------+
                                          |
                 +------------------------+------------------------+
                 |                                                 |
                 v                                                 v
    [ Closed-Form Solution ]                             [ Iterative Solution ]
  • Exact mathematical formula.                        • Start with a random guess.
  • Plug in data -> get answer instantly.              • Take small steps (gradients)
  • No loops, no iterations, no guessing.                until error stops decreasing.
  • Example: OLS Linear Regression.                    • Example: Gradient Descent,
                                                         Deep Neural Networks.
```

In this document, we solve Simple Linear Regression using the **closed-form OLS analytical derivation**. In future modules (Modules 5 & 6), we will explore Gradient Descent.

## Section 7: Visualizing the 3D Error Surface

Our OLS loss function is:

$$E(m, c) = \sum_{i=1}^n (y_i - m x_i - c)^2$$

Notice that for any specific choice of $(m, c)$, $E(m, c)$ outputs a single positive number.  
If you plot this in 3D:
* **$x$-axis:** Slope $m$
* **$y$-axis:** Intercept $c$
* **$z$-axis (Height):** Total squared error $E(m, c)$

```
         E(m, c) [Error]
            ^
            |       \               /
            |        \             /   <--- 3D Parabolic Bowl
            |         \___________/         (Convex Surface)
            |               |
            |       Global Minimum Point
            |          (m*, c*)
            +-----------------------------------> m (Slope)
           /
          /
         v  c (Intercept)
```

### The Magic of Convexity:
Because $E(m, c)$ is a sum of squared linear terms, the resulting 3D surface is a **strictly convex bowl**:
* It has **no local minima traps** or false valleys.
* It has exactly **one lowest point** in the entire universe of lines: the **global minimum**.
* At the absolute bottom of this bowl, the surface is completely flat in both directions.

In multivariate calculus, "flat in both directions" means both partial derivatives must equal zero simultaneously:

$$\frac{\partial E}{\partial c} = 0 \quad \text{and} \quad \frac{\partial E}{\partial m} = 0$$

Solving these two equations yields our optimal formulas for $c$ and $m$!

---

## Section 8: Step-by-Step Derivation of Intercept $c$ (Equation 1)

Let's derive the formula for the optimal intercept $c$ from scratch.

### Step 1: Write the Loss Function
$$E(m, c) = \sum_{i=1}^n (y_i - m x_i - c)^2$$

### Step 2: Take the Partial Derivative with Respect to $c$
Treat $m$, $x_i$, and $y_i$ as constants. Using the calculus chain rule $\frac{d}{dc}[u^2] = 2u \cdot \frac{du}{dc}$:

$$\frac{\partial E}{\partial c} = \sum_{i=1}^n \frac{\partial}{\partial c} (y_i - m x_i - c)^2$$

Let the inside term be $r_i = y_i - m x_i - c$.  
The derivative of $r_i$ with respect to $c$ is:

$$\frac{\partial}{\partial c}(y_i - m x_i - c) = 0 - 0 - 1 = -1$$

Therefore:

$$\frac{\partial E}{\partial c} = \sum_{i=1}^n 2(y_i - m x_i - c)(-1) = -2 \sum_{i=1}^n (y_i - m x_i - c)$$

---

### Step 3: Set Equal to Zero for the Minimum
$$-2 \sum_{i=1}^n (y_i - m x_i - c) = 0$$

Divide both sides by $-2$:

$$\sum_{i=1}^n (y_i - m x_i - c) = 0$$

---

### Step 4: Distribute the Summation Sign
$$\sum_{i=1}^n y_i - \sum_{i=1}^n m x_i - \sum_{i=1}^n c = 0$$

Since $m$ is a constant across all data points, factor it out:

$$\sum_{i=1}^n y_i - m \sum_{i=1}^n x_i - \sum_{i=1}^n c = 0$$

#### ⚠️ The Classic Student Trap: What is $\sum_{i=1}^n c$?
Many beginners mistakenly write $\sum c = c$. **That is completely wrong!**  
$c$ is a constant being added to itself $n$ times:

$$\sum_{i=1}^n c = \underbrace{c + c + c + \dots + c}_{n \text{ times}} = n c$$

Substituting this into our equation:

$$\sum_{i=1}^n y_i - m \sum_{i=1}^n x_i - n c = 0$$

---

### Step 5: Solve for $c$ and Introduce Sample Means
Move $n c$ to the right-hand side:

$$n c = \sum_{i=1}^n y_i - m \sum_{i=1}^n x_i$$

Divide every term by $n$:

$$c = \frac{1}{n}\sum_{i=1}^n y_i - m \left(\frac{1}{n}\sum_{i=1}^n x_i\right)$$

Recall the definitions of the sample means of $x$ and $y$:
* $\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$ (Mean of input feature $x$)
* $\bar{y} = \frac{1}{n}\sum_{i=1}^n y_i$ (Mean of target output $y$)

Substituting these gives:

$$\bar{y} - m\bar{x} - c = 0 \implies \mathbf{c = \bar{y} - m\bar{x}} \quad \text{--- (Equation 1)}$$

---

### 🌟 The Beautiful Geometric Insight
Rearranging Equation 1 gives:

$$\bar{y} = m\bar{x} + c$$

Look closely at this equation! It proves that if you plug the average input $\bar{x}$ into the regression line, the model outputs exactly the average target $\bar{y}$!

> 📌 **Golden Property of OLS:**  
> The best-fit OLS regression line is mathematically guaranteed to pass straight through the **center of mass (centroid)** of the data: **$(\bar{x}, \bar{y})$**.

---

## Section 9: Step-by-Step Derivation of Slope $m$ (Equation 2)

Now we need to find the optimal slope $m$.

### Why Substitute $c$ First?
Right now, our error function depends on two unknowns: $E(m, c)$.  
By substituting Equation 1 ($c = \bar{y} - m\bar{x}$) into $E(m, c)$, the unknown $c$ disappears completely! Our 2-variable optimization problem collapses into **a simple 1-variable problem in $m$**.

---

### Step 1: Substitute $c = \bar{y} - m\bar{x}$ into the Loss Function
$$E(m) = \sum_{i=1}^n \left( y_i - m x_i - (\bar{y} - m\bar{x}) \right)^2$$

Group the terms by $y$ and $x$:

$$E(m) = \sum_{i=1}^n \left[ (y_i - \bar{y}) - m(x_i - \bar{x}) \right]^2$$

---

### Step 2: Introduce Deviation Shorthand
To avoid messy algebra, let's define two simple shorthands for the deviations from the mean:
* Let $a_i = y_i - \bar{y}$ (how far $y_i$ deviates from its mean)
* Let $b_i = x_i - \bar{x}$ (how far $x_i$ deviates from its mean)

Rewriting our error function with this clean shorthand:

$$E(m) = \sum_{i=1}^n (a_i - m b_i)^2$$

---

### Step 3: Differentiate with Respect to $m$ Using Chain Rule
$$\frac{dE}{dm} = \sum_{i=1}^n 2(a_i - m b_i) \cdot \frac{d}{dm}(a_i - m b_i)$$

Since $a_i$ is constant with respect to $m$, $\frac{d}{dm}(a_i - m b_i) = -b_i$:

$$\frac{dE}{dm} = \sum_{i=1}^n 2(a_i - m b_i)(-b_i) = -2 \sum_{i=1}^n b_i(a_i - m b_i)$$

---

### Step 4: Set Equal to Zero and Expand
$$-2 \sum_{i=1}^n b_i(a_i - m b_i) = 0$$

Divide both sides by $-2$:

$$\sum_{i=1}^n b_i(a_i - m b_i) = 0$$

Multiply $b_i$ into the brackets:

$$\sum_{i=1}^n (b_i a_i - m b_i^2) = 0$$

Separate the summation:

$$\sum_{i=1}^n b_i a_i - \sum_{i=1}^n m b_i^2 = 0$$

Since $m$ is constant with respect to the index $i$, factor it outside:

$$\sum_{i=1}^n b_i a_i - m \sum_{i=1}^n b_i^2 = 0$$

---

### Step 5: Solve for $m$
$$m \sum_{i=1}^n b_i^2 = \sum_{i=1}^n b_i a_i$$

$$m = \frac{\sum_{i=1}^n b_i a_i}{\sum_{i=1}^n b_i^2}$$

---

### Step 6: Substitute Back the Original Deviations
Recall that $b_i = x_i - \bar{x}$ and $a_i = y_i - \bar{y}$:

$$\mathbf{m = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^n (x_i - \bar{x})^2}} \quad \text{--- (Equation 2)}$$

---

### 💡 Deep Intuition: Covariance Over Variance!
Look at the anatomy of this formula:
* **Numerator: $\sum (x_i - \bar{x})(y_i - \bar{y})$**  
  This measures the **Sample Covariance** between $x$ and $y$.  
  If $x$ and $y$ go up together, the numerator is positive (positive slope). If $y$ goes down when $x$ goes up, the numerator is negative (negative slope).
* **Denominator: $\sum (x_i - \bar{x})^2$**  
  This measures the **Sample Variance** of input feature $x$ (how much $x$ varies around its own mean).

$$\text{Slope } m = \frac{\text{Covariance}(x, y)}{\text{Variance}(x)}$$

#### ⚠️ What If All $x_i$ Values Are Identical?
Suppose every single student in your dataset had a CGPA of exactly $8.0$.  
Then for every student: $x_i - \bar{x} = 8.0 - 8.0 = 0$.  
The denominator $\sum (x_i - \bar{x})^2$ becomes **$0$**!  
Dividing by zero makes the slope **undefined** (a vertical line with infinite slope).  
**Rule:** You cannot fit a unique linear regression line if the input feature has zero variance!

## Section 10: The Complete OLS Recipe & Algorithm

Here is the exact algorithmic procedure for fitting any Simple Linear Regression model:

```
+-----------------------------------------------------------------------------+
|                     The 5-Step OLS Implementation Recipe                    |
+-----------------------------------------------------------------------------+
| 1. Compute Sample Means:                                                    |
|    x_bar = (1/n) * sum(x_i)                                                 |
|    y_bar = (1/n) * sum(y_i)                                                 |
|                                                                             |
| 2. Compute Deviations & Products:                                           |
|    Numerator   = sum[ (x_i - x_bar) * (y_i - y_bar) ]                       |
|    Denominator = sum[ (x_i - x_bar)^2 ]                                     |
|                                                                             |
| 3. Compute Slope m:                                                         |
|    m = Numerator / Denominator                                              |
|                                                                             |
| 4. Compute Intercept c:                                                     |
|    c = y_bar - m * x_bar                                                    |
|                                                                             |
| 5. Formulate Prediction Model:                                              |
|    y_hat = m * x + c                                                        |
+-----------------------------------------------------------------------------+
```

---

### 📝 Practice P9: Arrange the OLS Derivation Steps in Order

Arrange these 6 steps in chronological sequence:
* `[ 1 ]` Assume the linear model equation $\hat{y} = mx + c$.
* `[ 2 ]` Calculate the residual $e_i = y_i - \hat{y}_i$ at each data point.
* `[ 3 ]` Square each individual residual $e_i^2 = (y_i - mx_i - c)^2$.
* `[ 4 ]` Add all squared residuals to construct the total loss $E(m, c)$.
* `[ 5 ]` Minimize $E$ using partial derivatives ($\frac{\partial E}{\partial c} = 0$, $\frac{\partial E}{\partial m} = 0$).
* `[ 6 ]` Obtain the closed-form algebraic formulas for $m$ and $c$.

## Section 11: Complete Numerical Walkthrough by Hand

Let's put our formulas to the test with a real numerical dataset. Suppose we have 5 students tracking their **Study Hours ($x$)** and **Quiz Score ($y$)**:

| Student | Study Hours ($x$) | Quiz Score ($y$) |
| :---: | :---: | :---: |
| **P** | 1 | 25 |
| **Q** | 3 | 40 |
| **R** | 5 | 55 |
| **S** | 7 | 65 |
| **T** | 9 | 80 |

Let's compute the OLS best-fit line step-by-step!

---

### Step 1: Compute the Sample Means
$$\bar{x} = \frac{1 + 3 + 5 + 7 + 9}{5} = \frac{25}{5} = \mathbf{5}$$

$$\bar{y} = \frac{25 + 40 + 55 + 65 + 80}{5} = \frac{265}{5} = \mathbf{53}$$

The centroid of our dataset is $(\bar{x}, \bar{y}) = (5, 53)$.

---

### Step 2: Compute Deviations, Products, and Squares

| Student | $x_i$ | $y_i$ | $x_i - \bar{x}$ ($b_i$) | $y_i - \bar{y}$ ($a_i$) | $(x_i - \bar{x})(y_i - \bar{y})$ | $(x_i - \bar{x})^2$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **P** | 1 | 25 | $1 - 5 = \mathbf{-4}$ | $25 - 53 = \mathbf{-28}$ | $(-4) \times (-28) = \mathbf{112}$ | $(-4)^2 = \mathbf{16}$ |
| **Q** | 3 | 40 | $3 - 5 = \mathbf{-2}$ | $40 - 53 = \mathbf{-13}$ | $(-2) \times (-13) = \mathbf{26}$ | $(-2)^2 = \mathbf{4}$ |
| **R** | 5 | 55 | $5 - 5 = \mathbf{0}$ | $55 - 53 = \mathbf{+2}$ | $(0) \times (2) = \mathbf{0}$ | $(0)^2 = \mathbf{0}$ |
| **S** | 7 | 65 | $7 - 5 = \mathbf{+2}$ | $65 - 53 = \mathbf{+12}$ | $(2) \times (12) = \mathbf{24}$ | $(2)^2 = \mathbf{4}$ |
| **T** | 9 | 80 | $9 - 5 = \mathbf{+4}$ | $80 - 53 = \mathbf{+27}$ | $(4) \times (27) = \mathbf{108}$ | $(4)^2 = \mathbf{16}$ |
| **SUM ($\sum$)** | — | — | — | — | $\mathbf{270}$ | $\mathbf{40}$ |

---

### Step 3: Compute Optimal Slope $m$
$$m = \frac{\sum_{i=1}^5 (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^5 (x_i - \bar{x})^2} = \frac{270}{40} = \mathbf{6.75}$$

* **Interpretation:** For every additional hour a student studies, their expected quiz score increases by **$6.75$ marks**.

---

### Step 4: Compute Optimal Intercept $c$
$$c = \bar{y} - m\bar{x} = 53 - (6.75 \times 5) = 53 - 33.75 = \mathbf{19.25}$$

* **Interpretation:** If a student studies $0$ hours ($x = 0$), their baseline predicted score is **$19.25$ marks**.

---

### Step 5: Write the Final Best-Fit Model
$$\mathbf{\hat{y} = 6.75x + 19.25}$$

---

### Step 6: Make a Prediction for a New Student
Suppose a new student studies for **$6$ hours** ($x = 6$). What is their predicted quiz score?

$$\hat{y} = 6.75(6) + 19.25 = 40.50 + 19.25 = \mathbf{59.75 \text{ marks}}$$

---

### 🔍 Verification Reflections

#### Reflect 1: Does the line pass through $(\bar{x}, \bar{y})$?
Let's check by plugging in $x = \bar{x} = 5$:
$$\hat{y} = 6.75(5) + 19.25 = 33.75 + 19.25 = \mathbf{53} = \bar{y}$$
**Verified!** The prediction line passes directly through $(5, 53)$.

#### Reflect 2: What if every student studied exactly 5 hours?
Then $x_i = 5$ for all students.  
$x_i - \bar{x} = 0 \implies \sum (x_i - \bar{x})^2 = 0$.  
The denominator of $m$ would be $0$, which is undefined! A unique slope cannot be determined without variation in $x$.

## Section 12: Rapid Fire & Outlier Impact Analysis

### 📝 Practice P11: True / False Rapid Fire

| Statement | Answer | Rationale |
| :--- | :---: | :--- |
| **(a) The OLS line always passes through every single data point.** | **False** | It minimizes total squared error across all points, but almost never hits every point exactly unless the data is perfectly collinear. |
| **(b) The OLS line always passes through $(\bar{x}, \bar{y})$.** | **True** | Proven by $c = \bar{y} - m\bar{x} \implies \bar{y} = m\bar{x} + c$. |
| **(c) Squared error is more robust to outliers than absolute error.** | **False** | Absolute error is robust; squared error squares huge errors, making it highly sensitive to outliers. |
| **(d) The derivative of $|x|$ exists at $x = 0$.** | **False** | $|x|$ has a sharp corner at $0$ where the slope jumps from $-1$ to $+1$. |
| **(e) In $\hat{y} = mx + c$, $m$ and $c$ are learnable parameters.** | **True** | They are learned automatically from data by minimizing the loss function. |
| **(f) OLS gives an iterative (step-by-step) solution.** | **False** | OLS is a **closed-form** analytical formula solved in a single step. |
| **(g) If all $x_i$ values are identical, the slope $m$ is undefined.** | **True** | Denominator $\sum (x_i - \bar{x})^2 = 0$, leading to division by zero. |
| **(h) The error surface $E(m, c)$ is convex for SLR.** | **True** | It forms a single global bowl with no local minimum traps. |

### 📝 Practice P12: Outlier Impact Analysis

Suppose we add a 6th student to our dataset: **Student U ($x = 10, y = 20$)**.  
This student studied for 10 full hours but scored only 20 marks—a massive, abnormal outlier!

Let's analyze what happens to the loss functions:
1. **Under Absolute Error:**  
   $$\text{Penalty} = |e| = |20 - \hat{y}| = |20 - (10m + c)|$$  
   The penalty grows **linearly** with the distance from the line.
2. **Under Squared Error (OLS):**  
   $$\text{Penalty} = e^2 = (20 - \hat{y})^2 = (20 - (10m + c))^2$$  
   The penalty grows **quadratically**! If the line stays where it was ($\hat{y} \approx 86$), the residual is $20 - 86 = -66$.  
   The squared error penalty for this single point is $(-66)^2 = \mathbf{4,356}$!

> ⚠️ **The Consequence:**  
> To prevent a catastrophic penalty of $4,356$, the OLS optimization algorithm will aggressively tilt the line downward toward Student U.  
> **The OLS best-fit line will shift heavily toward the outlier**, sacrificing accuracy on the 5 normal students just to satisfy the single corrupt point.  
> **Fixes in Practice:** Remove corrupt outliers during EDA/Preprocessing, use **Huber Loss**, or switch to **Robust Regression (RANSAC / L1 Absolute Loss)**.

## 📋 Summary of Sheet 3 (Key Takeaways)

1. **The Model:** $\hat{y} = mx + c$ uses slope $m$ (tilt) and intercept $c$ (vertical shift).
2. **Residuals:** $e_i = y_i - \hat{y}_i$ are measured vertically because input $x$ is treated as fixed and error-free.
3. **Loss Functions:**
   * Signed error cancels out ($+10$ and $-10$ equal $0$).
   * Absolute error is robust to outliers, but has a sharp corner at $0$ blocking simple calculus.
   * **Squared error** is non-negative, smooth, differentiable everywhere, and yields exact closed-form formulas.
4. **The Centroid Rule:** The OLS best-fit line **always passes through $(\bar{x}, \bar{y})$**.
5. **The Two Core Formulas:**
   $$m = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2} = \frac{\text{Cov}(x, y)}{\text{Var}(x)}$$
   $$c = \bar{y} - m\bar{x}$$
6. **Outlier Warning:** Squared penalties pull the OLS regression line toward extreme data points like a heavy magnet.
